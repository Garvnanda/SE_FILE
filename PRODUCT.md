## Stack
User confirmed documented FastAPI, PostgreSQL/SQLAlchemy/Alembic, React/Vite/Tailwind stack. Implementation details delegated.

Students demonstrate a multi-user educational paper-trading application to software engineering faculty. Traders manage virtual portfolios; administrators govern accounts and instruments; market operators publish synthetic prices.
## Constraints
Native local Windows setup. No Docker and no deployment. No real money or external quotes. Provide source documentation for all thirteen experiments; student writes submissions. No invented team sign-offs.
## Brand commitments
TradeSphere; professional/formal technical interface, both light and dark themes.
